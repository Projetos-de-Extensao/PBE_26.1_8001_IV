## Introdução

<p align = "justify">
    O 5W2H é uma ferramenta administrativa  que pode ser utilizada para diferentes contextos dentro de uma organização, como na organização para planejamento estratégico e guia na execução de ações. O 5W2H baseia-se em 7 perguntas (What?, Why?, Where?, Who?, When?, How? e How much?), com o intuito de esclarecer e organizar ideias. A ferramenta será utilizada como um guia de ações, tornando os objetivos mais evidentes para a equipe, auxiliando na compreensão, organização e tomadas de decisões no projeto. 
</p>

## Metodologia

<p align = "justify">
    A equipe se reuniu para esclarecimento sobre o tema do projeto, a partir dos pontos debatidos foi possível responder às questões do 5W2H.   
</p>


## Questões 5W2H

### Versão 1.0

### Visão geral

| Elemento | Resposta |
| :--- | :--- |
| **What** | Desenvolvimento de uma API Backend para gestão e validação automática de propostas de estágio, com regras customizáveis por curso. |
| **Why** | Automatizar a conformidade legal (Lei 11.788/08) e acelerar o processo de avaliação de propostas do Ibmec. |
| **Who** | Alunos da turma 8001: Giovanna Perrone, Julia Valente, Luana Salles, João Pedro Nicacio e Maria Eduarda Perpetuo. |
| **Where** | Desenvolvimento via GitHub Codespaces e documentação MkDocs via GitHub Pages. |
| **When** | Realizado através de iterações durante o primeiro semestre de 2026. |
| **How** | Utilizando Django/Python para a lógica de negócio e seguindo a metodologia UP/RUP. |
| **How Much** | Aproximadamente 20h/semana de esforço da equipe, com custo financeiro zero (tecnologias Open Source). |


### Versão 2.0

### Visão produto

|Questão|Resposta|
|-------|--------|
|**What?** | Uma API  que recebe os dados dos contratos de estágio e aplica um motor de regras para validar automaticamente a conformidade com a Lei 11.788/08 e as diretrizes internas de cada curso do Ibmec.|
|**Why?** | Para amenizar o volume operacional dos coordenadores, além de reduzir o tempo de espera do aluno pela aprovação e minimizando erros humanos na conferência das regras acadêmicas e legais.|
|**Where?** |A API será feita por meio do GitHub utilizando a documentação MkDocs. Poderá ser hospedada em um ambiente de nuvem para que assim seja possível o acesso a mesma.|
|**When?** | O produto estará disponível para validar as propostas em tempo real no exato momento em que o aluno submeter o formulário ou documento no portal.|
|**Who?**| **Usuários diretos:** O sistema/portal do Ibmec (que consumirá a API).<br> <br>**Usuários indiretos:** Alunos (que submetem os documentos) e a equipe administrativa/coordenadores (que recebem os relatórios de validação).|
|**How?**| Através de endpoints que recebem os dados do estágio em formato JSON, processam essas informações contra as lógicas de negócio pré-configuradas no banco de dados e retornam um status (Aprovado/Reprovado) junto com os motivos detalhados em caso de pendências. |
|**How much?** |Possíveis custos de servidor em nuvem e banco de dados para manter a API no ar, porém, até o momento, o custo será zero.|


## Conclusão

A análise 5W2H, dividida entre a Visão Geral do projeto e a Visão do Produto, evidencia o alinhamento entre a necessidade do cliente e a  viabilidade técnica da execução.

Do ponto de vista do **Projeto (Visão Geral)**, o desenvolvimento se mostra viável, bem estruturado e focado em tecnologias de código aberto, garantindo assim custo zero. O uso de práticas ágeis e ferramentas modernas, como GitHub Codespaces e MkDocs, assegura que o esforço da equipe ao longo do semestre seja traduzido em um código limpo e uma documentação acessível.

Do ponto de vista do **Produto (Visão de Negócio)**, a API propõe resolver uma questão administrativa real e crítica. Ao automatizar a verificação das propostas de estágio em rigorosa conformidade com a Lei 11.788/08 e as regras internas do Ibmec, o sistema entregará valor contínuo. A solução reduzirá o tempo de espera dos alunos e minimizará a carga de trabalho manual dos coordenadores.

Em suma, trata-se de um esforço acadêmico que aplica conceitos de backend na prática para gerar uma solução de alto impacto operacional, modernizando e acelerando os processos da universidade.
O 5W2H é um técnica bem simples e de fácil entendimento, sem a necessidade de um especialista. Dentro da disciplina a técnica fornece um entendimento melhor, para a equipe, sobre o projeto como responsabilidades, motivação e organização de ações.
